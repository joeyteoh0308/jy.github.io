## How to use / 使用方法

1. **先读** `deal-cheatsheet-内部.md`，搞懂分成与你的诉求。
   **Read** the cheat-sheet first to understand the money flow and your asks.
2. 在 `ai-ugc-collaboration-proposal.md` 中填入：
   In the proposal, fill in:
   - `[合作方 / Partner Name]` → 合作方真实公司名 / partner's real company name
   - 分成比例与 RM 金额（示例 → 实际谈判数字）/ split % and RM figures (examples → negotiated numbers)
   - 各阶段成功指标 X,000 / XXX / XX / actual targets per phase
3. 导出 PDF 或直接发送提案文件给合作方。
   Export to PDF or send the proposal file to the partner.
